Marcus Ackre Medina är lärare i mjukvaruutveckling vid Nion Education, en yrkeshögskola (YH) i Sverige. Alla böcker är kostnadsfria, skrivna på svenska och anpassade för YH-studerande som siktar på jobb som mjukvaruutvecklare.

Materialet täcker: C# och .NET (från syntax till moderna C# 15-features — records, LINQ, generics, async/await och design patterns), Java-programmering (OOP, arv, interface och JVM-koncept), Git (versionshantering, branching, merge och GitHub-arbetsflöden), Microsoft Azure (molntjänster, App Service, Azure Functions och Blob Storage för C#-utvecklare), Projektmetodik (Scrum, Kanban och Vattenfall med roller, sprintar och retrospektiv) samt officiella reproduktioner av Usborne Computer Books — de klassiska 80-talsprogrammeringsböckerna med ZX81 och BASIC, publicerade med tillstånd av Usborne Publishing.
